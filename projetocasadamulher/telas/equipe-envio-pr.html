Como usar

1. Baixe ou use seu fork

Baixe a base do projeto ou trabalhe diretamente pelo Codespaces.

2. Envie sua alteração

Arraste o ZIP/pasta ou informe a branch usada no GitHub.

3. Revise antes do PR

O sistema compara com a main e cria PR apenas com arquivos alterados.

Regras de segurança

  • Arquivos idênticos são ignorados.
  • Arquivos sensíveis são bloqueados.
  • Alterações fora de protótipos geram alerta.
  • Nada é enviado sem sua confirmação.
